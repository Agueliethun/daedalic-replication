# Daedalic Replication

## What This Mod Is

A fabric mod for Minecraft 26.2.0 which is a spiritual descendant of Hostile Neural Nets. Create a data model and insert it into a replicator to create new output blocks using energy and time. 

Feed the model more input blocks in order to improve the efficiency of the model. The replicator will slowly accumulate energy over time on its own, but this mod is designed to be able to be incorporated into more technological packs. Future energy creation methods will probably be added as well.

All the learning and replication recipes are JSON driven, meaning you can easily create your own recipes for your mod/modpack, as well as modify or remove existing ones. To start out with, most of the vanilla non-renewables have been added.
In addition, you've got your stones, dirt, logs, and similar blocks.

Enchanting a model with fortune gives a chance of double output, while efficiency reduces learn/replicate time and energy usage.

JEI compatible.
